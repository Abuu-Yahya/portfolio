Live

built for real school work

Lengolink covers the day-to-day information schools need to manage, including parent and teacher portals, attendance and fee tracking. The platform is running live on Render and continues to be developed phase by phase.

My contribution spans the product structure, interface, backend, database and ongoing security improvements.

Challenge

School staff need clear access to attendance, fee and portal information.

Approach

Developing the interface, backend and database in deliberate phases, with security hardening.

Current outcome

The platform is live and continues to be developed.
